# Lynbro Cookie Consent

A free, multilingual and fully configurable **cookie consent banner for WordPress** —
GDPR / ePrivacy and **Google Consent Mode v2** ready out of the box, with an equally
prominent "Reject all" button, automatic tracker blocking, and **no pageview or domain
limits**. Everything runs locally: no account, no cloud, no external requests on the
front end.

🔗 **WordPress.org:** https://wordpress.org/plugins/lynbro-cookie-consent/
🌐 **Plugin page:** https://plugins.lynbro.dk/lynbro-cookie-consent

## Features

- ⚖️ Equal **Accept all / Reject all / Save preferences** — no dark patterns (Datatilsynet / EDPB aligned)
- 🔌 **Google Consent Mode v2** for free — all signals default to *denied* before consent
- 🛡️ Automatic blocking of well-known trackers (GA4, GTM, Meta Pixel, Hotjar, Clarity, LinkedIn, TikTok …)
- ▶️ Embed/iframe placeholders (YouTube, Vimeo, Google Maps, social, reCAPTCHA) with zero layout shift
- 🌍 **35 bundled languages** — including all 24 official EU languages — with cache-safe auto-detect & switcher
- 🧾 Local **proof-of-consent log** (no raw IP, anonymised hash) + CSV export
- 📊 Private, **cookieless statistics** in your own database
- 🇺🇸 **GPC** + CCPA / CPRA "Do Not Sell or Share" link
- 🎨 No-code design: themes, layouts, colours, live device preview, WCAG-AA contrast check
- 🔗 WP Consent API compatible · ♿ WCAG 2.1 AA · ⚡ cache & performance friendly

## Install

From your dashboard: **Plugins → Add New → search "Lynbro Cookie Consent" → Install → Activate**.
The banner goes live immediately with safe, GDPR-ready defaults.
